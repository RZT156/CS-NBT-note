# CPU和外设间信息交换
### 输入/输出接口端口
端口（Port）：I/O接口电路中可通过编程寻址并进行读/写的**寄存器**
CPU对接口访问基本上可认为是对**端口的读写**
接口包含：数据端口、控制端口、状态端口

### 输入/输出一般过程
输入过程： 
(1)CPU 把一个地址值放在地址总线上，选择某一*输入*设备；
(2)CPU *等候*输入设备的数据成为有效；
(3)CPU 从数据总线*读入*数据，并*放*在一个相应的寄存器中

输出过程：
(1)CPU 把一个地址值放在地址总线上，选择一个*输出*设备；
(2)CPU 把数据*放在数据总线*上；
(3)输出设备认为数据有效，从而把数据*取*走
### I/O 接口与外设间的数据传送
1. 无条件传送方式
2. 应答方式(异步传送方式)
3. 同步传送方式
### CPU 与 I/O 接口间的数据传送
1. 程序查询方式
2. 程序中断方式
3. DMA方式

# CPU与I/O间数据传送

## 程序查询方式
CPU主动去查询外设，读I/O状态
检查状态未准备就绪时，**踏步等待**
		准备就绪后，数据传送
## 程序中断方式
CPU在正常运行程序时，由于内外部事件引起CPU暂时中止正在运行的程序，转去执行请求CPU暂时中止的内、外部事件的服务程序，待该服务程序处理。完毕后又返回到被中止的程序的过程。

特点：
1. 外设主动通知CPU，CPU不查询
2. CPU和外设并行工作
3. 没有踏步等待

> *I/O设备准备就绪后向CPU发出中断请求。CPU执行中断服务程序完成数据传送。占用CPU时间。*
## DMA方式
直接内存访问 direct memory access
CPU让出总线控制权，DMAC——DMA控制器全权控制存储器与I/O之间直接进行高速的数据传送
