# 2.1 数据与文字的表示方法
## 定点与浮点
### 定点数
只表示纯整数或纯小数
小数：每位权重为$2^{-n}$
最大绝对值：$2^{-1}+2^{-2}+……+2^{-n} = 1-2^{-n}$
最小绝对值：$0$

整数：$0<=|x|<=2^{n}-1$
### 浮点数
表示方法：$2^{e} · M$ ，类比十进制中$10^{E} · M$
M是**尾数**，纯小数；e是**指数**，整数；2是**基数**
==阶码E：指数用移码表示==（真值$_{10}$+偏置值）
==尾数M：尾数用原码表示==
符号位+阶码E(n个)+数符+尾数M(m个)

### 浮点数机器表示
**IEEE754标准**
32位短浮点数$x=(-1)^S\times(1.M)\times2^{E-127}$ 
$e=E-127$, 127是指数偏移值
*E直接根据二进制数计算对应十进制*
- 阶码全为0/移码=0时，指数固定为-126
- 阶码全为1/移码=255时，表示NaN，无指数

| S 31 | E 30-23 | M 22-0 |
| ---- | ------- | ------ |
64位长浮点数$x=(-1)^S\times(1.M)\times2^{E-1023}$

## 机器码表示
### 原码
最高位符号位，正数补0，负数补1
### 反码
正数不变，负数取反，符号位不变
### 补码
正数不变，负数在反码基础上+1
16位补码表示范围从1000 0000 0000 0000到0000 0000 0000 0001
$-2^{15}\~+2^{15}-1$ 最小值原码无法表示，最大值原码对应为0111 1111 1111 1111
作补码**相反数**时，各位取反再+1
### 移码
补码的基础上符号位取反，只表示整数。
相当于原码连带符号位全部取反再+1
比大小很方便
![[移码用于数值比较.png|300]]
### 整数的数位拓展
数字由短变长（补码表示）
- 零拓展 无符号数，用0拓展
- 符号拓展 带符号数，正数用0，负数用1（反了原值会变）
### 其他
有阶符、数符->题中给出为补码
有数符->说明是定点小数

## 移位运算
**逻辑移位 无符号整数**
左移丢弃位为1时，溢出，≠×2
右移同理，但丢失精度，高位补0
**算数移位 带符号**
左移前后符号位改变，溢出
右移高位补符号位
## 加/减法
### 带符号
$[x+y]_补=[x]_补+[y]_补  \quad ( mod\quad 2^{n+1})$
符号位也参与计算
$[x-y]_补=[x]_补+[-y]_补$
$[-y]_补 = -[y]_补$

**溢出判断**
上溢：数值超出可表示范围
正溢：正+正=负
负溢：负+负=正
下溢：仅浮点数，绝对值接近0
双符号位法/变形补码：
正数符号00，负数符号11
01正溢，10负溢

## 定点乘法
### 无符号
1. **手算模拟**
2. **Booth乘法**
![[乘法硬件实现.png|400]]
### 带符号
1. 原码相乘，分离符号位和绝对值。绝对值计算同上，符号异或取值
2. 补码相乘(**Booth乘法**)
如果p+x超出n位（变成n+1位），就用n+1位的结果，Y多移一位
结果通常保留低n位
![[screenshot_20260920_221445_yylx.danmaku.bili.png|400]]
溢出判断：
高n+1位不全相等，说明溢出，OF=1（无符号乘法溢出时CF=1&OF=1,但是一般看OF）
### 主要的三种方式：
1. 阵列乘法器，最快，通常一个时钟周期
2. ALU，移位器，寄存器，控制逻辑组成的电路，多个时钟周期
3. 移位，加减法等效实现乘法
## 定点除法
![[除法硬件实现.png|400]]
n bit / n bit单精度，2n bit / n bit双精度
统一化为2n bit / n bit（无符号数零拓展，带符号数符号拓展）
最终得到n bit商，n bit余数

开始前的统一操作：
除数放入寄存器Y；被除数放入寄存器R & Q；计数器`Cn = n;`
### 无符号
开始：
	特殊情况处理：
	- 除数为0，发生*异常*，停止运算，调出异常处理程序；
	- 被除数 < 除数，商 = 0，余数 = 被除数，不必执行除法
中间进行n+1轮（因为商最大为n+1位）：
	上商规则：**R-Y≥0，上商1，否则0**
	第一轮特殊处理：第一位商为1，发生 *"商溢出"异常*，停止运算；为0，不必保存，Cn不必-1，继续
	其余n轮：
	1. 左移，最右侧空出位上商
	2. 上商，商为0则**R=R-Y+Y**，为1则R=R-Y
	3. `Cn--`，当Cn=0时结束
结束：
	n bit寄存器R保存余数，n bit寄存器Q保存商
### 带符号
![[screenshot_20260922_213006_yylx.danmaku.bili.png]]
特殊情况判断：（都是在n轮处理前执行）
- 除数为0，发生*异常*，停止运算，调出异常处理程序；
- 被除数 < 除数，商 = 0，余数 = 被除数，不必执行除法
- 仅 绝对值最大的负数 ÷ -1 会发生 *“商溢出“异常*（对于补码单精度除法）
中间了解即可
结束：
	Cn=0，n bit R保存余数，n bit Q保存商
