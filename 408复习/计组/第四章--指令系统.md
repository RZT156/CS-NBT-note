# 4.1 指令格式
一条指令通常包括**操作码**和**地址码**
$A_1$指某个主存地址，$(A_1)$括号内所指向地址中的内容
### 按地址码个数
一条指令根据地址码数目不同，分为：三地址指令，二地址指令，一地址指令，零地址指令
1. 三地址指令，格式：op, A1, A2, A3
A1, A2 为源操作数地址，A3 为目的操作数地址
]$(A_1)OP(A_2)->A_3$ 访存4次：取指->读A1->读A2->写A3

1. 二地址指令，格式：op, A1, A2
A1既是源操作数地址也是目的地址；A2源操作数

两个操作数的算术运算、逻辑运算相关指令
$(A_1)OP(A_2)->A_1$ 访存4次：取指->读A1->读A2->写A1

2. 一地址指令
一个操作数：如+1，-1，取反，求补等。$OP(A_1)->A_1$，访存3次（取指->读A1->写A1）
两个操作数，但一个操作数已存入特定位置（如ACC寄存器），访存2次（写入不需要访存，写入的是ACC寄存器）

3. 零地址指令：OP
不需要操作数，如空操作(NOP)，停机(HLT)等
堆栈（后缀表达式计算）
### 按指令长度分
**指令长度**：一条指令的总长度，是*机器字长* 整数倍 [[计组/第二章--运算方法和运算器#^60e5a4|机器字长由ALU运算位数决定]] 
1. 定长指令字结构
2. 变长指令字结构
### 按操作码长度分
1. 定长操作码 n位->$2^n$条操作码
2. 变长操作码

**扩展操作码**：定长指令字结构+变长操作码
操作码字段位数不固定
设计指令格式时 不允许短码是长码前缀（对比哈夫曼树）
通常使用频率高的操作码分配短
### 按操作类型分 
1. 数据传送
LOAD，把存储器数据放到寄存器
STORE，把寄存器数据放到存储器
2. 运算
算术，逻辑，移位
3. 程序控制类
无条件转移 JMP
条件转移     JZ
调用CALL、返回RETURN
4. 输入输出类
CPU和I/O之间
# 4.2 寻址方式
确定指令或操作数内存地址的方式
## 指令寻址
下一条指令存放地址，始终由PC给出
**顺序寻址**
定长指令字结构，pc每次按指令字长（x个字节）固定增大
**跳跃寻址**
JMP、CALL等转移类指令改变pc指向
## 操作数寻址
确定地址码指明的有效地址
形式地址（A）指令中显示给出地址
有效地址（EA）由寻址方式和形式地址A共同确定
1. **直接寻址**，指令字中的形式地址A就是操作数的有效地址EA，EA=A
优点 只访问一次主存
缺点 A的位数决定寻址范围；操作数地址不易修改
2. **间接寻址**，形式地址A是操作数存储单元的地址，有效的是EA，EA=(A)
优点 扩大寻址范围；便于编程（子程序返回）
缺点 多次访存
3. **寄存器寻址**，指令字中给出操作数所在寄存器编号，EA=R_x
优点 ==无访存==，只访问寄存器
4. **寄存器间接寻址**，EA=(R_x)
比一般间接寻址快
5. **隐含寻址**，操作数在专用寄存器
优点 ==无访存==，访问专用寄存器；缩短指令字长
缺点 增加硬件
6. **立即寻址**，指令给出操作数，*立即数*
优点 ==无访存==
缺点 A的位数限制立即数范围
7. **偏移寻址**
偏移起点不一样
- **基址**寻址 EA=(BR)+A ==程序起始存放地址==
面向操作系统，基址寄存器BR
- **变址**寻址 EA=(IX)+A  ==自定义起点==
面向用户，形式地址A作为基地址不变
- **相对**寻址 EA=(PC)+A ==PC下一条指令所指地址==
偏移量A是相对下一条指令而言（因为pc会+1）
8. 其他寻址方式
堆栈寻址，使用堆栈指针作为操作数地址
主存/专用寄存器中一块按后进先出原则管理的存储区
软堆栈/硬堆栈
注意栈顶在高地址端还是低地址端
# 4.3 x86机器指令
## 汇编指令介绍
### 数据存放在寄存器、主存、指令
在寄存器（exx里找），在主存（按地址\[]找），在指令（立即数）
**地址** \[xxxxxh]
**字长**
word ptr单字
dword ptr双字
byte ptr字节
指令中未给出字长，==默认32位==
**寄存器** exx
通用寄存器eax,ebx,ecx,edx,变址寄存器esi,edi,堆栈寄存器ebp,esp
通用寄存器无e 16bit，有e 32bit
EAX32位—>AX16位->AH前8位,AL后8位
### 操作码常用指令
Intel格式：指令助记符 d，s
指令助记符记英文
s源地址 可以来自指令（立即数），d目的地址 不可以。
除法隐藏被除数。基本d = d \[操作] s。
**算术类**
加ADD，减SUB，乘MUL，除DIV/IDIV（有i的是带符号运算），负NEG，自增INC（++），自减DEC
**逻辑类**
与AND，或OR，非NOT，异或XOR(e**x**clution **or**)，左移SHL，右移SHR
**数据转移**
复制值MOV ==不支持两个操作数都在主存（访存速度慢）==
**分支循环**
比较CMP（本质减法，产生4个[[第二章--运算方法和运算器#^2253fa|标志位]]），（零判断？）TEST（按位与，更新ZF），跳转JMP
**函数调用**
入栈PUSH，出栈POP，回调CALL，返回RET

## 选择语句
**无条件转移**
JMP NEXT
NEXT:操作符 数据
**条件转移**
je (equal) =
jne (not equal)不等于
jg jge (greater than)＞ ≥
jl jle(less than)＜≤
用法：
cmp a,b
jxx next
## 循环语句
**条件转移指令**
四步：
1. 循环前初始化
2. 是否直接跳过
3. 主体
4. 是否继续循环
**Loop指令**（简洁一点）
loop Looptop，默认ecx循环计数器，等于以下三步
自减dec ecx
判断cmp ecx,0
不为0继续循环jne Looptop
## 函数调用
调用call，被调用ret回到call的下一条
栈顶低地址，栈底高地址
call指令：
1. 把pc下一条指令地址压入栈（相当于push ip，\[esp-4]=\[ip]，函数返回地址）
2. 更新pc寄存器为函数调用地址（相当于jmp 「函数名」）
**访问栈帧**
push pop或者mov
**切换栈帧**
进入enter
push ebp把栈顶esp-4，ebp里的值压入栈（栈顶元素变成*上个栈的基地址*）
mov ebp, esp（ebp指向esp地址，成为新栈的基地址）
返回leave
mov esp,ebp
pop ebp（栈顶esp出栈，这个地址的元素是*上个栈的基地址*，赋值给ebp）
