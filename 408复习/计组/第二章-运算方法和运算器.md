# 2.1 数据表示方法
## 定点与浮点
### 定点数
只表示纯整数或纯小数
小数：每位权重为$2^{-n}$
最大绝对值：$2^{-1}+2^{-2}+……+2^{-n} = 1-2^{-n}$
最小绝对值：$0$
整数：$0≤|x|≤2^{n}-1$
### 浮点数
**IEEE754标准** $x=(-1)^S\times(1.M)\times2^{e}$
基数：十进制10，二进制 2
==🟣阶码e：用移码表示==（十进制真值+偏置值）
尾数M：用原码表示，默认忽略小数点前那个1
符号位+阶码E(n个)+数符+尾数M(m个)
#### 32位float浮点数
$x=(-1)^S\times(1.M)\times2^{E-127}$
$e=E-127$, 127是指数偏移值
`符号S` 1位，`移码E` 8位，`尾数M` 23位
#### 64位double浮点数
$x=(-1)^S\times(1.M)\times2^{E-1023}$
`符号S` 1位，`移码E` 11位，`尾数M` 52位

## 整数机器码表示
### 原码
最高位符号位，正数补0，负数补1
### 反码
正数不变，负数取反，符号位不变
### 补码
正数不变，负数在反码基础上+1
16位补码表示范围从1000 0000 0000 0000到0000 0000 0000 0001
$-2^{15}\~+2^{15}-1$ 最小值原码无法表示，最大值原码对应为0111 1111 1111 1111
作补码**相反数**时，各位取反再+1
### 移码
补码的基础上符号位取反，只表示整数。
相当于原码连带符号位全部取反再+1

### 整数的数位拓展
数字由短变长（补码表示）
- 零拓展 无符号数，用0拓展
- 符号拓展 带符号数，正数用0，负数用1
## 浮点数特殊处理
**规格化数**
阶码全1，尾数全0->无穷
阶码全0，尾数全0->0

**非规格化数**，阶码全0/1，尾数不全0
小数点前隐含0，非1
阶码全0，尾数不全0->float=$2^{-126}$,double=$2^{-1022}$
阶码全1，尾数不全0->NaN
### 下溢
数值落入非规格化数区间，按机器零处理
下溢到机器零，算下溢异常，754规定计算机不中断程序

# 2.2 定点数的运算
## 加法器
一位全加器，$A,B$两个输入，$C_i$作为进位信号。所以加法运算为$S_i = A_i+B_i+C_{i-1}$

**行波进位（串行进位）**
- 一位全加器（FA），最基本加法单元
- 串行进位加法器：n个全加器相连得到n位加法器
- 进位信息串行产生，有延迟
![[一位全加器原理.png]]

并行进位的并行加法器可以解决延迟问题

**带标志位的加法器**
OF(overflow flag) 溢出，==带符号数==加减运算是否溢出。1溢出；0未溢出
SF(sign flag) 符号标志，==带符号数==加减运算结果正负。1负；0正
ZF(zero flag) 零标志，加减运算结果是否为0。1为零；0不为零
CF(carry flag) 进位/借位，无符号数加减运算是否溢出。和OF一致

### 算数逻辑单元ALU

## 移位运算
**逻辑移位 无符号整数**
左移丢弃位为1时，溢出，≠×2
右移同理，但丢失精度，高位补0
**算数移位 带符号**
左移前后符号位改变，溢出
右移高位补符号位
## 加/减法
### 带符号
$[x+y]_补=[x]_补+[y]_补  \quad ( mod\quad 2^{n+1})$
符号位也参与计算
$[x-y]_补=[x]_补+[-y]_补$
$[-y]_补 = -[y]_补$

**溢出判断**
上溢：数值超出可表示范围（正溢负溢都是上溢）
正溢：正+正=负
负溢：负+负=正
下溢：仅浮点数，绝对值接近0

双符号位法/变形补码：
正数符号00，负数符号11
01正溢，10负溢

单符号位法：

方法二：最高位和次高位进位$C_i⊕C_{i-1}$，也是OF的判断逻辑
### 无符号
加法：
最高位进位=1，溢出

减法：加`减数`的`补码`
最高位进位=0，则溢出

无溢出时丢弃进位即答案
## 定点乘法
### 无符号
1. **手算模拟**
2. **Booth乘法**
![[乘法硬件实现.png|400]]
### 带符号
1. 原码相乘，分离符号位和绝对值。绝对值计算同上，符号异或取值
2. 补码相乘(**Booth乘法**)
如果p+x超出n位（变成n+1位），就用n+1位的结果，Y多移一位
结果通常保留低n位
![[32位带符号数乘法电路结构.png|400]]
溢出判断：
高n+1位不全相等，说明溢出，OF=1（无符号乘法溢出时CF=1&OF=1,但是一般看OF）
### 主要的三种方式：
1. 阵列乘法器，最快，通常一个时钟周期
2. ALU，移位器，寄存器，控制逻辑组成的电路，多个时钟周期
3. 移位，加减法等效实现乘法
## 定点除法
![[除法硬件实现.png|400]]
n bit / n bit单精度，2n bit / n bit双精度
统一化为2n bit / n bit（无符号数零拓展，带符号数符号拓展）
最终得到n bit商，n bit余数

开始前的统一操作：
除数放入寄存器Y；被除数放入寄存器R & Q；计数器`Cn = n;`
### 无符号
开始：
	特殊情况处理：
	- 除数为0，发生*异常*，停止运算，调出异常处理程序；
	- 被除数 < 除数，商 = 0，余数 = 被除数，不必执行除法
中间进行n+1轮（因为商最大为n+1位）：
	上商规则：**R-Y≥0，上商1，否则0**
	第一轮特殊处理：第一位商为1，发生 *"商溢出"异常*，停止运算；为0，不必保存，Cn不必-1，继续
	其余n轮：
	1. 左移，最右侧空出位上商
	2. 上商，商为0则**R=R-Y+Y**，为1则R=R-Y
	3. `Cn--`，当Cn=0时结束
结束：
	n bit寄存器R保存余数，n bit寄存器Q保存商
### 带符号
特殊情况判断：（都是在n轮处理前执行）
- 除数为0，发生*异常*，停止运算，调出异常处理程序；
- 被除数 < 除数，商 = 0，余数 = 被除数，不必执行除法
- 仅 绝对值最大的负数 ÷ -1 会发生 *“商溢出“异常*（对于补码单精度除法）
中间了解即可
![[带符号定点除法中间过程.png]]
结束：Cn=0，n bit R保存余数，n bit Q保存商
# 2.3 浮点加减运算
**补码加减**
float单精度浮点数 32位 $x=(-1)^S\times(1.M)\times2^{E-127}$ 
Double双精度 64位 $x=(-1)^S\times(1.M)\times2^{E-1023}$

运算步骤：
- 对阶（阶码一致，小阶向大阶对齐）
- 尾数求和（和负数作补码运算）
- 规格化（二进制整数部分为1）
- 舍入（大多数0舍1入）
- 溢出检查（阶码位数）
### 舍入
末尾溢出位为100时，末位（小数点后第23位）0—>截断；末位1—>进位
### 溢出
上溢时，阶码全1，尾数置全0
下溢时，如果阶码已为00000001，尾数仍需左规，则尾数不变，阶码置全0
