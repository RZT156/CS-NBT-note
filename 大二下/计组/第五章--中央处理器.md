# 流水线技术与流水线处理器
## 五阶段
取指令IF fetch
译码ID decode
RISC处理器中，数据一定来自通用寄存器
执行EX execute
访存M memory
写回WB writeback（有可能不需要）
 
**性能指标**
1. **吞吐率TP** 单位时间完成任务数量
$TP=\frac{n}{T_k} \approx \frac{1}{\Delta t}$，一条指令可能包含k个阶段，一条指令需要一个机器周期，也即k个时钟周期
2. **加速比** 不使用流水线时间：使用流水线时间
$S=\frac{T_0}{T_k}=\frac{k \times \Delta t \times n}{(k+n-1)\Delta t} \approx k$
3. **效率** 设备利用率，忙碌时间占总时间比例。可以用n个任务占时空区有效面积 ：总面积

## 影响因素
**结构相关（资源冲突）**
多条指令同一时刻争用同一资源
解决办法：
1. 后一相关指令暂停一周期
2. 资源重复配置：数据存储器+指令存储器
**数据相关（数据冲突）**
前一条指令和后一条指令共用某个存储器内数据
