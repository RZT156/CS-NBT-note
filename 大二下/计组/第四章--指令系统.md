# 指令格式
一条指令通常包括操作码和地址码
$A_1$指某个主存地址，$(A_1)$括号内所指向地址中的内容
### 操作码op
指出操作性质，即指令完成功能
n位操作码存储$2^n$条指令
### 地址码ad
操作数地址（主存中）
n位地址码直接寻址范围$2^n$
指令总长一定时，地址码数量越多，寻址能力越差
### 指令字长度
**指令字长**：一条指令的总长度，影响取指令所需时间（访存次数）
半字长指令，单字长指令，双字长指令...
**指令字长=机器字长的xxx倍**
机器字长：CPU进行一次整数运算能处理的二进制数位数

1. 等长指令字结构：各种指令字长度相等
指令的读取和分析硬件结构简单
2. 变长指令字结构：指令字长度随功能而变化

# 指令和数据寻址方式
==寻址方式：形成指令或操作数内存地址的方式==
形式地址（A）指令中显示给出地址
有效地址（逻辑地址）操作数或指令实际地址
有效地址（EA）由寻址方式和形式地址共同确定==（求操作数的真实地址）==
## 指令寻址方式
指令寻址：确定下一条指令存放地址，始终由PC给出
**顺序寻址**
定长指令字结构，pc每次固定增大
**跳跃寻址**
JMP、CALL等转移类指令改变pc指向
## 操作数寻址方式
数据寻址：确定本条指令地址码指明的真实地址
1. **直接寻址**，指令字中的形式地址A就是操作数的有效地址EA，EA=A
优点 只访问一次主存
缺点 A的位数决定寻址范围；操作数地址不易修改
2. **间接寻址**，形式地址A是操作数存储单元的地址，有效的是EA，EA=(A)
优点 扩大寻址范围；便于编程（子程序返回）
缺点 多次访存
3. **寄存器寻址**，指令字中给出操作数所在寄存器编号，EA=R_x
优点 无访存，只访问寄存器（速度快！）
4. **寄存器间接寻址**，EA=(R_x)
比一般间接寻址快
5. **隐含寻址**，操作数在专用寄存器
优点 无访存，访问专用寄存器；缩短指令字长
缺点 增加硬件
6. **立即寻址**，指令给出操作数（也叫*立即数*）
优点 无访存
缺点 A的位数限制立即数范围（A有n位，立即数采用补码，表示的范围$-2^{n-1}-2^{n-1}-1$）
7. **偏移寻址**
偏移起点不一样
- **基址**寻址 EA=(BR)+A ==程序起始存放地址==
面向操作系统
- **变址**寻址 EA=(IX)+A  ==自定义起点==
面向用户，形式地址A作为基地址不变
- **相对**寻址 EA=(PC)+A ==PC下一条指令所指地址==
偏移量A是相对下一条指令而言（因为pc会+1）
8. 堆栈寻址，使用堆栈指针作为操作数地址
主存/专用寄存器中一块按后进先出原则管理的存储区
软堆栈/硬堆栈
注意栈顶在高地址端还是低地址端
9. 段寻址 基址寻址的一种特例。地址长度超过字长
段地址和机器字长相等，与段内偏移量错位相加
对用户透明

# 典型指令
## 分类
### 按地址码长度分
一条指令根据地址码数目不同，可能包含0~多个地址码
按地址码字段个数分类：三地址指令，二地址指令，一地址指令
1. 三地址指令，格式：op, a1, a2, a3
a1, a2 为源操作数地址，a3 为目的操作数地址
特点：
- 两个操作数的算术运算、逻辑运算相关指令。
- 指令字长较长，难以支撑ss型指令
$(A_1)OP(A_2)->A_3$ 访存4次：取指->读A1->读A2->写A3

1. 二地址指令，格式：op, a1, a2
a1既是源操作数地址也是目的操作数地址；a2源操作数
特点：
两个操作数的算术运算、逻辑运算相关指令
$(A_1)OP(A_2)->A_1$ 访存4次：取指->读A1->读A2->写A1
减少指令字长度/增加地址码字段位数/为操作码扩展提供支持
一个源操作数会被替代

2. 一地址指令
格式：
AC <- (AC) OP (A) 在二地址指令格式基础上，一个地址设定到专用寄存器中
特点：
- 只需要一个操作数：如+1，-1，取反，求补
$OP(A_1)->A_1$ 访存3次：取指->读A1->写A1。（访存是访问主存） 
- 两个操作数，但一个操作数已存入特定位置

4. 零地址指令：OP
- 不需要操作数（空操作(NOP)，停机(HLT)等）
- 堆栈（后缀表达式计算）
